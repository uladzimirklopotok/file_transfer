# 🪟 Как переименовать компьютер в Windows

---

## Способ 1 — через «Параметры» (графический интерфейс)

1. Откройте **Параметры** → **Система** → **О системе**.
2. Нажмите **Переименовать этот компьютер**.
3. Введите новое имя и нажмите **Далее**.
4. Перезагрузите компьютер.

---

## Способ 2 — через PowerShell (от имени администратора)

```powershell
Rename-Computer -NewName "Новое-Имя" -Restart
```

---

## Способ 3 — через командную строку (CMD)

```cmd
wmic computersystem where name="%COMPUTERNAME%" call rename name="Новое-Имя"
```

---

> ⚠️ **Важно:** после переименования обязательно перезагрузите компьютер, чтобы изменения вступили в силу.
