# 🐧 Как переименовать компьютер в Linux

В Linux имя компьютера называется **hostname**. Ниже — несколько способов его изменить.

---

## Способ 1 — через `hostnamectl` (рекомендуется)

```bash
sudo hostnamectl set-hostname новое-имя
```

Проверить результат:

```bash
hostnamectl
```

---

## Способ 2 — вручную через файлы

1. Откройте файл `/etc/hostname` и замените содержимое на новое имя:

   ```bash
   sudo nano /etc/hostname
   ```

2. Обновите файл `/etc/hosts`, чтобы новое имя соответствовало `127.0.1.1`:

   ```bash
   sudo nano /etc/hosts
   ```

3. Перезагрузите систему:

   ```bash
   sudo reboot
   ```

---

> 💡 **Совет:** имя должно содержать только латинские буквы, цифры и дефис.
